# Seeds for batch `register1`: swearing and current slang

## Why

- Zero-shot RuadaptQwen3-4B keeps the swearing in 65.4% of the crude probes; after the QLoRA run rua-q1
  it keeps it in 34.6%, with 0.0 refusals and 0.0 masking. The fine-tune taught it to be cleaner.
- The training data is almost free of profanity. In `dataset/train.jsonl` (3,451 rows), the tier regex
  in `model/podtekst_sft/crude.py` finds 16 Russian rows with any crude word (mostly хрен, жопа, задница)
  and **one** with strong mat, plus 3 English rows with strong profanity. The test set has one crude
  Russian row, so this cannot be measured there.
- In the 53-sentence comparison with Google, Yandex and DeepL, Podtekst lost most on swearing
  (26/48 vs 39-43/48) and on current slang.

So the fix is data. The on-device model does not need to be uncensored.

## Targets

About 900 train rows and about 100 held-out test rows after Stage B. Seeds are over-generated by about
20% to allow for rejects and Cowork drops. The grid lives in `generate_register_seeds.py`
(`TRAIN_TOTAL`, `TIER_WEIGHT`, `FUNCTIONS`, `SLANG`, `TEST_PER_TIER`); `--dry-run` prints it.

### Train, 1,095 seeds (`seeds_register1.txt`)

| Language | strong | medium | mild | slang | total |
|---|---:|---:|---:|---:|---:|
| RU | 243 (27 per function) | 162 (18) | 135 (15) | 60 | 600 |
| EN (EN->RU) | 225 (25) | 144 (16) | 126 (14) | -- | 495 |

RU : EN is 55 : 45. Strong is weighted heaviest (45% / 30% / 25%) because that is where the fine-tune
lost the most.

Tiers (the same lists as the eval metric):
- mild: блин, чёрт, фиг/пофиг/офигеть, капец; damn, crap, hell, heck, freaking
- medium: хрен, хер, жопа, задница, сволочь, говно, дерьмо, срать; ass, bastard, dick, prick, piss, bloody,
  bollocks, goddamn
- strong: хуй / пизд / ебать / блядь / сука families, мудак; fuck, shit, bullshit, motherfucker, asshole, bitch

Functions (each tier x language cell is split evenly over all nine):
interjection, intensifier, insult at a person, insult at a thing or situation, dismissal, idiomatic mat
(хуй знает, нахуй, какого хрена), friendly banter between close friends, swearing inside sarcasm, and
formal vs informal setting (half the lines at work or to a boss, half to a friend). Every English row is
the EN->RU direction for its tier.

Slang, 60 RU rows, 6 per term, current forms from the native-speaker review (`slang_updates.csv`):
загоны, по красоте, ору / это ор, рофл, треш, пофиг / побоку / без разницы, красава, на вайбе, запарка,
збс. Dated forms (пучком, фиолетово, прикол, угораю) are not requested; the guidelines name them only as
what to avoid when choosing a translation.

### Test, 100 seeds (`seeds_register1_test.txt`)

50 RU + 50 EN, per language strong 22 / medium 15 / mild 13. They come from a separate run with one
mixed-function prompt per cell, are checked against the train seeds, and never enter train. After
Stage B they become `model/probes/profanity_test.jsonl` and are scored together with the 24 existing
crude probes in the eval's `profanity` report (`profanity_kept_rate_by_tier`: within one tier of the reference; `profanity_same_tier_rate_by_tier` is strict). The 380-row test set is
unchanged.

## Filters on every generated line

- 4-18 words, natural chat or spoken register.
- Profanity of exactly the requested tier (not softer, not harsher); slang rows are exempt.
- No masking (`f***`, `б**ть`), no slurs about protected groups, no personal names, no real people,
  no lines from films, songs or books. Film-derived text stays local and is not used here.
- New against every `seeds_*.txt` (film seeds included, only as a duplicate check), the current dataset,
  the eval probes and the pilot sentences (normalised: lower case, punctuation stripped).

## Translation rules

`config/calibration_guidelines.md`, section "Profanity and slang register". Stage A gets it with
`--rules-section "Profanity and slang register"`; Cowork reads it as part of the guidelines.

## Pipeline

    python pilot_register1.py                                     # generator choice
    python generate_register_seeds.py --split train --out seeds_register1.txt --model <chosen>
    python generate_register_seeds.py --split test  --out seeds_register1_test.txt --model <chosen>
    python stage_a_generate.py --seeds seeds_register1.txt --out stage_a_register1.jsonl \
        --failures stage_a_register1.failures.jsonl --rules-section "Profanity and slang register"
    (retry_failures.py with the same --rules-section, then deterministic_checks.py)
    python register_checks.py --in stage_a_register1.clean.jsonl    # stop if kept (within one tier) < 85%
    python stage_b_prefilter.py --in stage_a_register1.clean.jsonl ...  ->  Cowork
